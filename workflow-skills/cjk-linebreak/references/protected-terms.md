# 保護詞彙表：通用清單與維護方式

斷詞工具是用一般語料訓練的，遇到品牌名稱、專業用語，甚至一些很常見的詞都可能切錯。表上的詞一律不拆。

## 通用清單

以下是實際專案中被 BudouX 或 `Intl.Segmenter` 拆錯過的詞，已經內建在 `scripts/add_wbr.py`。React 專案請依需要複製到 `cjkWordBreak.ts` 的 `PROTECTED_TERMS`。

| 類別 | 詞彙 |
|---|---|
| 健康與專業 | 物理治療師、物理治療、人體工學、心理諮商、體適能、肌耐力、肌力、中高齡、血壓、量血壓、常模、量測、步數、判讀、正確率、中位數 |
| 常用詞 | 自己、日常、生活、理解、了解、數位、紀錄、取代、下載、微小、個人、每日、每天、情境、連結、創造、成效、數字、工具、真的、不只、不是、而是、哪裡、並非、身心、把關、放進、計入、載入、等同 |
| 片語 | 下一步、做得到、用得上、有跡可循、每一次、拿得到 |
| 數量詞 | 一次、一下、一件、一個、一天、一步、一點、一間、一筆、五分鐘 |
| 公司用語 | 有限公司、健康科技 |

## 專案自己要加的詞

- **品牌與產品名稱**：例如福聚徠、動齡、艾力賀、福幣、健康護照
- **英文產品名稱**：例如 `Google Play`、`Health Connect`（中間有空白，要整個保護）
- **這個專案特有的專業用語**

靜態網站把這些詞放進專案的 `protected-terms.txt`（一行一個詞，`#` 開頭是註解），執行時用 `--terms` 指定。

## 維護方式

1. **改了文案就重新檢查**：用 `python add_wbr.py 檔案.html --show` 印出切詞結果，逐句檢查。
2. **發現被拆開的詞**：加進保護詞彙表，並註明發現的日期，例如 `# 2026-10-14 人工檢查發現`。
3. **長的詞放前面**：例如「物理治療師」要排在「物理治療」前面。`add_wbr.py` 會自動依長度排序，React 模板則要自己注意順序。
4. **重要的詞加進測試**：避免之後修改時又被拆開。
5. **不要保護太長的句子**：保護詞彙會變成不能換行的一整塊，太長的話在窄螢幕上可能超出畫面。一般以 2～6 個字為原則。
