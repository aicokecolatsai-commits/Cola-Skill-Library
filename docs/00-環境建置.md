## 安裝方式

### Git
```powershell
winget install --id Git.Git -e --source winget
```

### GitHub CLI
```powershell
winget install --id GitHub.cli -e --source winget
```

### uv
```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### Codex Desktop App
從 OpenAI 官方下載並安裝。

## 注意事項
- Windows PowerShell 可能會擋 `npx.ps1`，MCP 設定請使用 `npx.cmd`
- 讀取文件時請使用 UTF-8 編碼
